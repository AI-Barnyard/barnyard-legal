## How to Use These URLs

1. **Post-payment message:** After a customer completes payment on Stripe, their order confirmation page can include these download links.
2. **Email confirmation:** Send these URLs in an automated or manual email confirmation.
3. **Access security:** These URLs rely on obscurity (unguessable paths), not authentication. Standard for static-hosted digital products.

## Important Notes

- Each URL is a unique cryptographic hex string — 24 characters of randomness per product.
- URLs will remain active as long as files exist on GitHub Pages.
- Do NOT commit these URLs to public repos or include in public documentation.
- Share only with paying customers.
